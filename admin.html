Вход администратора

Важно: это вход только для администратора (отдельная учётка в базе). Пароль от личного кабинета клиента/помощника сюда не подходит.

Откройте эту страницу по адресу http://localhost:3000/admin.html (пока запущен npm start). Если открыли файл с диска — вход не сработает без сервера.

Email по умолчанию: traceur95@mail.ru, пароль: из ADMIN_PASSWORD в .env или AdminTeplo2026! Сброс: npm run reset-admin
